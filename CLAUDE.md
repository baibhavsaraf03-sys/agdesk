# Ledge Desk (repo: agdesk) — notes for Claude

Read this instead of exploring. Grep for the names below; do not read `app/page.jsx` whole.

## Layout
- `app/page.jsx` (3,000 lines, the entire UI). Find things by grep: `function TVWidget`, `function Grid`, `function Block`, `function FXScreen`, `screen === "MAC"` (one block per screen code: HOME, WLD, ASIA, EMEA, AMER, GRN, SFT, MAC, FX, DOOM, JRN...).
- `app/globals.css` — all styles, one line per rule. `.grid/.grow/.gnm/.gpx/.gch` is the three-column quote grid; `.srcs` is the source-link list.
- `lib/tv.js` — every TradingView symbol (`TAPE`, `TV_GROUPS` keyed by screen code).
- `lib/geo.js` — political-risk flashpoints, keyword matching and the shipping/trade/air-travel markers for the GEO screen. It reads the existing news streams; it measures reporting, never probability.
- `lib/content.js` — static copy, `FALLBACK_FEED` (shown when no live read), `ZONES`.
- `lib/quotes.mjs` — verified figures per zone (ECB FX, Treasury curve, BIS rates, FRED).
- `lib/news.mjs`, `lib/providers.mjs` — free headlines and the Gemini/Anthropic writers.
- `scripts/feed-read.mjs` — the scheduled read. Schema is `READ_TOOL`; output goes to Supabase `market_reads`, served by `app/api/feed/route.js`, read in the page as `reads[zone]` (`ag` is the agricultural one).
- `.github/workflows/feed.yml` — one hourly cron (minute 23, every day) that runs all seven reads in turn (`ams eur doom ag eas ind anz`). Each read works out its own phase from the zone's local clock (`phaseNow` in `scripts/feed-read.mjs`: open, midday, close, overnight, weekend) and is skipped when its figures and headlines hash to the same `material` as the last read of the same phase under six hours old (`--force` overrides). Writers in order: Gemini free (`gemini-flash-lite-latest`, then `gemini-flash-latest`; variable `GEMINI_HOURLY_MODELS`), Groq free if the `GROQ_API_KEY` secret exists (`GROQ_FEED_MODELS`, requests too big for a model's per-minute limit are skipped without a call), then Anthropic (billed) only when `FEED_ALLOW_PAID` is 1 (the default) and the zone's read is over `FEED_PAID_AFTER_HOURS` (default 6) old. If all fail the old read stays up. `payload.writer` records which one wrote it. Manual run: Actions → Market reads (zone `all` or one, phase `auto` or fixed, force).
- Articles (`/articles`, built 11 Nov): `app/articles/page.jsx` (published list), `[slug]/page.jsx` (one article), `submit/page.jsx` (sign-in, form, the writer's own submissions), `review/page.jsx` (editor's queue; returns 404 to everyone else). Reads in `lib/articles.js`, shared limits in `lib/article-rules.js`, all client-side pieces in `components/ArticleForms.jsx`, writes in `app/api/articles/route.js` and `app/api/articles/review/route.js`. Table, row-level security and the editor list are in `supabase/migrations/20261111_articles.sql`. No service-role key is used: the policies decide everything, and the editor is whoever has a row in `article_editors` (set with `select public.set_article_editor('<sign-in email>')` in the SQL editor; the address is deliberately not in the repo). Article bodies render through `lib/markdown.jsx` with class `doc-body`.
- Accounts (11 Nov): sign-in is Google or a one-time email link, both run by Supabase Auth; no passwords, no 2-factor (owner's choice). `/signin` (`?next=` and `?error=<code>`), `/account` (details, sign out, delete), `/privacy`. Components in `components/Account.jsx`; deletion in `app/api/account/route.js` (service role, server only). `app/auth/callback/route.js` finishes both kinds of sign-in, returns to the path in the `ld_next` cookie if `lib/auth-paths.js` allows it (else `/#JRN`), and sends failures to `/signin?error=` with a fixed code. Email links need custom SMTP in Supabase (the built-in mailer only reaches the Supabase team); until then the form says email sign-in is not switched on. The privacy page names the analyst provider from `AGENT_PROVIDER`; keep it accurate if anything new is stored.
- Charts (CHT, 11 Nov): `components/Charts.jsx` is the whole screen (layout 1/2/4, shared timeframe and indicator switches, symbol list, typed symbols, saved in `agdesk.charts`). Each chart is TradingView's free Advanced Chart widget, embedded the way TradingView's React example does it (container plus a script whose text is the JSON config), not by building the iframe like `TVWidget`. Symbol list, shorthands (`CHT GOLD`, `CHT CABLE`, `CHT NASDAQ:AAPL`) and indicator ids are in `lib/charts.js`, built from `TV_GROUPS` plus a Currencies group. `ChartLinks` in `app/page.jsx` puts a row of "Chart" chips under every quote table; `openChart(symbol)` and `chartReq` carry the request to the screen. The page's `.wrap` gets `.wide` on CHT.
- Watchlist (WL, 11 Nov): `components/Watchlist.jsx` holds the screen and `useWatchlist(user)`, which the page calls once because three things change the list: the WL screen, the Watch button on CHT, and the command bar (`WL GOLD` adds gold). Signed in, the list is one row in the `watchlist` table through `app/api/watchlist/route.js` (GET, PUT of the whole list; no service role, the policies decide). Signed out, it is `agdesk.watch` in the browser; at sign-in the browser's list is added to the account's and then removed from the browser. Limit (40), symbol check and the quote-table config are in `lib/watchlist.js`. Quotes are the same Market Quotes widget as the other screens (`TVWidget`), so the same feed rules apply. Table and policies: `supabase/migrations/20261111_watchlist.sql`. If the table is missing, signed-in visitors see a "could not be loaded" line and the browser list.
- Alerts (ALR, 12 Nov): web push notifications, no app. `components/Alerts.jsx` is the screen (device on/off, new-alert form, list, recent alerts; needs an account). Four kinds, rules and validation in `lib/alert-rules.js` (`cleanAlert`, `describeAlert`, `headlineMatches`: whole words, plurals allowed), decisions in `lib/alert-decide.mjs` (pure functions, tested): `release` (lib/calendar.js, lead 5/15/60/1440 min, sent up to 10 min late rather than dropped), `price` (fires on crossing; once then off, or every crossing), `headline` (the reads' publisher RSS feeds, every 15 min; first run learns silently), `doom` (verdict change in `reads.doom.tabs`; first run learns). Checker: `scripts/alerts-check.mjs`, run by `.github/workflows/alerts.yml` every 5 minutes (`--probe` checks the price and headline sources without the database; run it from Actions with "probe"). Prices: `lib/prices.mjs`, Yahoo Finance chart API then Stooq CSV, free and delayed; only symbols in `PRICE_MAP` plus NASDAQ:/NYSE: shares can carry an alert (B3 farm futures excluded: priced in reais); `/api/price` shows the visitor the exact number an alert is checked against. Routes: `/api/alerts` (GET, POST, PATCH on/off, DELETE; RLS, no service role), `/api/push` (GET public key, POST/DELETE this device), `/api/price`. Push: `public/sw.js` (shows notifications, opens the screen on tap; caches nothing), `web-push` in the checker with `VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY` GitHub secrets and `VAPID_PUBLIC_KEY` in Vercel; keys are made in the owner's browser at `/tools/push-keys` (never in chat or the repo). Without keys alerts are still recorded and shown under Recent alerts. Tables, policies and limits (25 alerts, 10 devices per account, cascade on account delete): `supabase/migrations/20261112_alerts.sql`. iPhones receive notifications only once the site is added to the home screen (manifest + `apple-touch-icon.png`). Shortcuts: "Remind me" on CAL rows, "Alert" on WL rows, "Alert me when a verdict changes" on DOOM tabs, all through `openAlert(kind, params)`.
- Meme stocks (MEME, 12 Nov): `components/Meme.jsx`, reading `reads.meme` (same `market_reads` table, zone `meme`, no SQL). `scripts/meme-read.mjs`, hourly at minute 41 (`.github/workflows/meme.yml`; `--probe` prints the table without the database, `--summary` forces a new summary): top 25 r/wallstreetbets tickers by 24-hour mentions from ApeWisdom (free, no key; the site never calls Reddit, whose free API is closed to new apps and blocks unauthenticated requests), price, day change and volume against the 20-day average from Yahoo daily bars (`lib/meme.mjs`). Labels (`classify`): Rally (mentions up by half or more and price +5%, or price +10% on 2x volume), Buzzing (talk surge, no price move), Selling off (talk surge, price -5%). `NOT_TICKERS` drops words the counter mistakes for tickers (YOU, DTE, CEO...); add to it when one turns up. AI summary about every 7 hours on free writers only (Gemini, then Groq; never Anthropic), told to give no recommendations and to say when headlines show no reason. Rows link to Chart, Watch, Alert (NASDAQ/NYSE names only, via `memeSymbol`) and "Why?" (the analyst). Not in the Beginner set.
- `proxy.js` — Next.js 16 uses this, not `middleware.js` (adding one breaks the build).
- Currencies (FX, 11 Nov): `app/api/fx/route.js` returns `{ rates, positioning, events, status }` for `FXScreen` in `app/page.jsx`. No database and no key. `lib/fx.mjs` fetches policy rates (BIS), the US 2-year (Treasury), the euro 2-year (ECB yield curve, AAA governments) and hedge-fund positioning (CFTC Traders in Financial Futures, dataset `gpe5-46if`, leveraged funds), each cached half an hour per server instance with the last good answer kept; the route is edge-cached 15 minutes. `status` in the response says per source `ok` or why it failed: open `/api/fx` to check. The route passes only USD/EUR/GBP/JPY events to the screen. Styles are the `.fx*` rules at the end of `globals.css`.
- Calendar (CAL, 11 Nov): `components/Calendar.jsx`, reading `lib/calendar.js` directly in the browser (no route). `lib/calendar.js` is written out by hand from the publishers' calendars because no free feed exists; each series has `key`, `tier`, `currencies`, publisher `zone` and `time` (daylight saving is computed), `about` copy, official `source` URL and optional `span` (minutes an unfixed announcement can land after the stated time: the Bank of Japan, 75). Series: Fed, ECB, BoE, BoJ, Bank of Canada, RBA, US jobs, US CPI, US GDP first estimate, UK CPI, euro flash inflation. THE LISTS END IN DECEMBER 2027 (euro flash in March 2027, US GDP after 28 Jan 2027): extend them. The screen groups by day in the visitor's chosen zone (device, London, New York, Tokyo), filters by currency, major-only and range, shows the last 24 hours as released, has "Ask the analyst", per-event and bulk `.ics` downloads, and keeps settings in `agdesk.cal`. `CAL USD` filters from the command bar (`calReq`). Dates only by design: no consensus or actual figures, since no free feed has them. Styles are `.cal-*` at the end of `globals.css`.

## TradingView widget rules (learned the hard way)
- The free widget only quotes some feeds. Working: `INDEX:`, `FOREXCOM:` (SPXUSD, NSXUSD, UKXGBP), `BSE:`, `TSX:TSX`, `BMFBOVESPA:`, `SSE:`, `SZSE:`, `EURONEXT:AEX`, `BME:IBC`, `OMXSTO:`, `CMCMARKETS:` metals/cotton, `TVC:USOIL`.
- Blank or error: `CBOT:`, `NYMEX:`, `ICEUS:`, `ICEEUR:` futures; `TVC:` yields; `CBOE:`; `AMEX:`; `ASX:`, `NZX:`, `TSE:`, `TWSE:`, `NSE:`, `MIL:`, `BIST:`, `TADAWUL:`, `JSE:`; `PEPPERSTONE:AU200AUD`; `FOREXCOM:DJI`.
- A symbol existing on tradingview.com does not mean the widget shows it. Remove a blank row rather than guess a replacement.
- Iframes that change config need a `key` or React keeps the old one.

## Naming
- The site is called Ledge Desk (drawn as LEDGE·DESK). The repo, the Vercel URL and the `agdesk.*` localStorage keys keep the old name on purpose: renaming the keys would wipe visitors' saved progress.

## Interface conventions
- Noir (12 Nov, owner's choice; design canvas "Ledge Desk redesign directions" in claude.ai): the default theme is `data-theme="dark"`, restyled as Noir at the end of `globals.css` (black, hairlines, square corners, `.cut` panels with one corner cut, champagne gold `--gold` for serif capitals and the short rule under headings, green only for up/live/needles, falls in grey with a minus sign; Doto `--dots` for instruments and clocks, Geist `--sans`/`--mono`, Cormorant Garamond `--serif` for headings, Source Serif `--read` for prose). Light stays as the "Light" option (`agdesk-theme`); the boot script applies only an explicit light. Home opens with `components/Instruments.jsx` (five dials: S&P 500, FTSE 100, the mood dial, gold, AI exposure = Doomsday tabs with verdict "supports"; the hour's brief = newest market read's `short`; next tier-1 release countdown; S&P 500 session line; positions of note). Prices and mood: `/api/pulse` from `lib/pulse.mjs` (Yahoo, delayed; mood read off the VIX in fixed bands, documented there and on the screen). The menu is a full-screen sheet (`components/Nav.jsx`; columns on wide screens, folding areas on phones; "Essential"/"Full desk" are the old beginner/pro values; Escape closes). The landing opens with "the door" (clock, one line, Enter/Sign in). Share card: `app/card/route.jsx` (1080×1920; `?format=og` 1200×630 is the site-wide link preview set in `app/layout.jsx`); "Share today's card" hands it to the phone's share sheet or downloads it. Manual Actions workflow "Site check" prints what the live `/api/pulse`, `/card` and `/api/fx` return.
- No emoji or glyph icons, no feature-card grids, no inline `style={{}}` for new work. Use the tokens and classes in `globals.css`; serif for headings, sans for text, mono only for codes and figures.
- Navigation (12 Nov, owner's choice): `lib/nav.js` groups screens into five areas (Today, Markets, Commodities, Learn, My desk; Help and Terms in the menu footer) and lists the `BEGINNER` set. `components/Nav.jsx` is the menu: a jump box (searches screen names, codes and descriptions; `findExtra` adds "Chart: Gold" when the words name a market), a Beginner/Pro switch (`agdesk.navmode`; first visits default to Beginner, anyone with `agdesk.screen` saved to Pro; Beginner hides the rest behind "N more in Pro" but they stay reachable by search, links and codes), and collapsible areas. Areas open and close with + / − (owner's choice; no counts). No bottom bar on phones (tried and dropped at the owner's request, 12 Nov); on phones the menu is the drawer behind the top-left button, and Plain English and the theme switch move from the top bar into it. A new screen goes in `SCREENS` and in one area of `NAV_AREAS`.
- Colours: the Doomsday charts use `--dn` and `--rule`, which the sheet never defined (bars drew black); they are now aliases of `--down` and `--line` at the end of `globals.css`.
- Phones: touch screens get 40px minimum tap targets (`@media(pointer:coarse)`), nothing a reader needs is under 11.5px under 620px, and the Doomsday SVG charts (`.dchart-wrap`) keep a 520px minimum width and scroll sideways rather than shrink their labels.
- The analyst renders from `analystBody(side)` both on the AGN screen and in the side panel (`agnOpen`). `ask(text, shown)` opens the panel; `shown` is the label displayed instead of a long prompt.
- DOOM has a live layer above its tabs: `reads.doom` (zone `doom`, rewritten hourly, news filtered by `AI_TRADE_RE` in `lib/doomsday.js`), a TradingView tile (`TV_GROUPS.DOOM`) and live headlines. The tabs below it are the static argument in `lib/doomsday.js`; each tab opens with a "Where this stands now" box from `reads.doom.tabs[]` (`verdict`, `note`, `now` paragraphs, up to four `figures`), owner's choice 11 Nov: the AI writes the current view on top and never rewrites the argument itself. Reads published before 11 Nov have no `now` and show `note` only.
- Reads carry `short` (three plain sentences, shown by `InShort`) and, for `ag`, `macro`.
- To look at the site locally: `NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:9 NEXT_PUBLIC_SUPABASE_ANON_KEY=local-dummy npx next build` then `next start` with the same two variables. Without them every page returns a 500. News and widgets are empty offline.

## Working rules
- Verify with `npx next build` before pushing. Push to `main`; Vercel deploys automatically.
- Ship patches (commits), never bulk copies of the repo.
- Never give the owner a command containing a placeholder value.
- Running costs should stay near zero: Gemini free tier first, Groq free tier second, Anthropic only to stop a read going six hours stale (owner's choice, 11 Nov). Do not make the paid step run more often without asking.
- Reference pages (START, TUT, RISK, GLOS, MTD, TERMS, HELP, disciplines, FLOW, `/learn`, `/glossary`) are fixed on purpose and are not rewritten by the reads.
- Supabase `service_role` key is server-only: never `NEXT_PUBLIC_`, never in the browser.
